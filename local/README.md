# local/

Runtime data directory. Everything here is machine-local and gitignored except this README.

## Purpose

Holds the live database, generated artifacts, logs, and caches produced by the
paper-trading runtime and admin commands. Nothing in here is committed — the repo's
`.gitignore` matches `local/*` and re-includes only `local/README.md` — so the folder
safely holds machine-specific state and is recreated on demand.

## Usage

- Most subdirectories are created automatically the first time a job writes to them.
- `db_config.json` is the one file you may edit by hand; it points the app at the database.
- Safe to clear when reclaiming space: `cache/` (regenerated on next run) and old files
  under `logs/`, `exports/`, and `db_backups/`. Do **not** delete `paper_trading.db`.
- The generated installer scripts (`install_trading_timers.sh` /
  `uninstall_trading_timers.sh`) are disposable — regenerate before each use.

## Files

| Path | Purpose |
|---|---|
| `paper_trading.db` | Live SQLite database for all trading data |
| `db_config.json` | Points the app at `paper_trading.db` (or an override path) |
| `install_trading_timers.sh` | Generated by `manage_job_schedules` — run once with `sudo bash` to install systemd timers. **Regenerate before each use** (it embeds machine-specific paths); delete after installing. |
| `uninstall_trading_timers.sh` | Generated by `manage_job_schedules --unregister` — run with `sudo bash` to remove systemd timers. |

## Subdirectories

### `db_backups/`
Weekly `.db` snapshots created by the `weekly_db_backup` maintenance job.
Files are named `paper_trading_YYYYMMDD_HHMMSS.db`.
The canonical path constant is `DB_BACKUPS_DIR` in `common/paths/project_paths.py`.

### `logs/`
Per-run `.log` files written by the scheduler jobs.
- `daily_paper_trading_YYYYMMDD_HHMMSS.log` — daily trading run output
- `daily_paper_trading_startup_YYYYMMDD.log` — scheduler startup log for that date
- `daily_snapshot_YYYYMMDD_HHMMSS.log` — equity snapshot run output
- `daily_backtest_refresh_YYYYMMDD_HHMMSS.log` — backtest refresh run output
- `weekly_db_backup_YYYY_Www_YYYYMMDD_HHMMSS.log` — weekly backup run output
- `*_scheduler.log` — rolling persistent log for each scheduler process (not per-run)

The canonical path constant is `LOGS_DIR` in `common/paths/project_paths.py`.

### `exports/`
JSON and CSV artifacts written by jobs and admin commands.
The canonical path constant is `EXPORTS_DIR` in `common/paths/project_paths.py`.

| Subdirectory | Contents |
|---|---|
| `daily_paper_trading/` | JSON run summary per trading day (`daily_paper_trading_YYYYMMDD_HHMMSS.json`) |
| `daily_snapshots/` | JSON equity snapshot per day (`daily_snapshot_YYYYMMDD_HHMMSS.json`) |
| `daily_backtest_refresh/` | JSON backtest refresh summary per day |
| `db_csv_YYYYMMDD_HHMMSS/` | Manual CSV exports of DB tables (created by `python -m trading.interfaces.cli.main export-db-csv`) |
| `db_csv_YYYYMMDD_HHMMSS.zip` | Zipped versions of the CSV export directories above |

### `cache/`
Runtime caches. The market data cache lives at `cache/market_data/` as hash-named `.pkl` files.
Cache entries have a 24-hour TTL enforced at read time in `trading/services/market_data/cache.py`.
Stale `.pkl` files are not actively evicted from disk and accumulate over time.

### `charts/`
PNG chart images generated by `trends/charts.py` (hardcoded to this path).
Not referenced from `project_paths.py`.

### `screenshots/`
UI screenshots captured by `python -m scripts.screenshot_ui`.
The canonical path constant is `SCREENSHOTS_DIR` in `common/paths/project_paths.py`.
Used for visual QA and UI development reference.

### `.stfolder/`
Marker directory created by Syncthing when this folder is synced across machines.
Not used by the application; present only if you sync `local/`.
